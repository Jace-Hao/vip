# 洗衣管家 · 会员数据导出工具（v1.1）

一键导出「洗衣管家」里的会员数据，自动生成排版好的 Excel 文件。
全程在本机运行、**只读操作**，不会修改软件里的任何数据、不做任何界面点击。

**两个使用入口：**

| 入口 | 用时 | 导出内容 |
| --- | --- | --- |
| **导出会员数据.cmd**（日常推荐） | 几秒钟 | **所有会员**的常规表（9 列）+ **全量字段表**（会员档案全部字段，62 列） |
| **导出会员数据(含详情).cmd**（完整版） | 首次全量约 1~2 小时；日常增量几分钟 | 上面全部内容 + 逐会员**详情**：标签、充值/赠送余额构成、卡券、**订单明细**（每笔订单号/金额/时间）、最近充值信息等；**增量更新**：仅重新获取新增/有变更的会员；支持中断续传；**全程不停顿**：仅相邻请求自动限速（约 2~3 秒/会员），取数失败仅短暂延时（数秒~数十秒）后自动重试 |

**收衣收银系统（可替代软件日常收衣）：** 双击 **`打开收衣页面.cmd`**（自动拉起本地服务并打开）。五大功能：**收衣开单**（会员搜索/建档、品类录入、折扣抹零、余额支付真实扣减、58mm 小票）、**订单管理**（收衣→送洗→完成→取件 流转、挂账单结算）、**会员管理**（资料编辑、充值含赠送、历史与流水）、**流水账**、**统计**（今日/本月营收、充值、支付分布）。数据存本机「收衣数据」目录（orders.json/ledger.jsonl/members_local.json），服务开机自启、口令保护；**不写洗衣管家软件**，余额独立核算。

**浏览与查询：** 双击 **`打开会员查询页面.cmd`**，会在浏览器中打开「会员数据查询台」，
可搜索、筛选、查看每位会员的全部资料与订单/卡券详情；每次导出后页面数据会自动刷新。

---

## 使用方法

1. 确认「**洗衣管家**」已经打开并登录（正常营业状态即可）。
2. 双击运行对应入口（日常用第一个，要完整数据用第二个）。
3. 等待完成提示后，会自动打开 `导出结果` 文件夹。
4. 打开最新的 Excel 文件即可查看、编辑、打印。

> 核对小技巧：完成后会显示“会员总数”和“账户余额合计”，可与洗衣管家会员页顶部的统计做对照。

## 输出文件说明

每次运行会在 `导出结果` 文件夹生成一组文件（以运行时间命名）：

| 文件 | 用途 |
| --- | --- |
| `会员导出_xxx.xlsx` | 常规表：联系人 / 电话 / 级别 / 余额 等 9 列，**日常使用推荐** |
| `会员全量数据_xxx.xlsx` | 全量字段表：会员档案的全部字段（62 列；金额字段单位为“分”） |
| `会员详情_xxx.xlsx` | （含详情模式）详情总表 + 订单明细 + 卡券明细 |
| `会员导出_xxx.csv`、`会员全量数据_xxx.csv` | 通用表格文件（Excel / WPS 直接打开） |
| `会员导出_xxx.json`、`会员详情_xxx.json` | 原始数据（供程序使用 / 备份） |

常规表包含 9 列：

| 列名 | 说明 |
| --- | --- |
| 联系人 | 会员姓名（部分会员未登记姓名，显示为空） |
| 电话 | 手机号（固定为文本格式，不会变成科学计数法） |
| 会员级别 | 如：VIP会员 / 全价会员 / 代收点 |
| 账户余额(元) | 当前账户余额，单位：元 |
| 会员卡号 | 有实体卡时显示卡号；空 = 未办卡 |
| 订单数 | 历史订单笔数 |
| 注册时间 | 会员注册时间 |
| 来源 | 微信公众号 / 店内 等 |
| 状态 | 正常 / 禁用 |

## 浏览与查询（会员数据查询台）

完成任意一次导出后，双击 **`打开会员查询页面.cmd`**：

1. 脚本会把最新的「全量数据 + 详情」合并生成页面数据（几秒）；
2. 随后在浏览器中打开本地查询页面（离线可用，无需联网、无需服务器）。

查询页面功能：

- **搜索**：姓名 / 电话 / 拼音 / 卡号 / 订单号 / 标签 / 备注，实时过滤并高亮；
- **筛选**：会员级别、来源、状态、余额区间；**排序**：注册时间 / 余额 / 订单数 / 姓名；
- **详情面板**：点击任意会员，查看账户与余额、消费统计、卡券、全部原始字段；
- **订单记录**：已抓取订单详情的会员，可展开每笔订单的衣物明细、照片、支付记录（其余会员显示最近订单摘要）；
- **一键复制**：复制电话 / 姓名+电话；
- **导出筛选结果 CSV**：把当前筛选结果导出为表格文件。

> 小提示：每次运行导出（常规或含详情）后，查询页面的数据会**自动刷新**；也可以随时手动双击
> `打开会员查询页面.cmd` 重新生成并打开。

自定义（可选）：页面样式变量在 `查询页面/index.html` 顶部的 `:root{...}`（主色、圆角、配色）；
标题、每页条数等也可在该文件内直接调整。

## 常见问题

**1. 提示“无法连接洗衣管家调试端口”怎么办？**
先确认洗衣管家正在运行且已登录。若反复出现：完全退出洗衣管家，双击运行
`以调试模式启动洗衣管家.cmd` 重新打开软件，然后再导出。

**2. 提示 Excel 生成失败？**
CSV 文件同样可以打开使用；若需要排查，请把屏幕上方的错误信息发给维护者。

**3. 全量字段里的金额为什么是“分”？**
为保持原始数据不失真，全量字段表按系统存储单位（分）导出；常规表的余额列已换算成“元”。

**4. 含详情模式中途断了怎么办？**
重新运行同一个入口即可：会自动跳过已抓取成功的会员、继续补抓（断点续传）。
导出**全程不停顿**：相邻请求自动保持约 2~3 秒间隔；遇到取数失败仅短暂延时（数秒~数十秒）后自动重试，无需人工干预；
只有当连续 30 分钟完全没有进展时才会自动停止（数据均已保存，重跑可继续）。
如需更保守的节奏，可设置环境变量加大请求间隔，例如 `set LAUNDRY_MIN_INTERVAL_MS=5000` 后再运行。

**5. 会不会影响洗衣管家正常使用？**
不会。工具只读取数据：不修改内容、不代替人工点界面、不影响收衣开单和打印流程。

**6. “散客 / 临时用户”会导出吗？**
不会。当前导出的是“会员”列表。如需导出散客数据，可联系维护者增加。

**7. 后续更新数据会不会很慢？“增量更新”是什么意思？**
不会。再次运行「含详情」导出时，工具会先把最新数据与上次比对：**没变化的会员直接使用已存详情，只重新抓取“新增会员”和“数据有变化的会员”**（如余额变动、新订单、资料修改等）。日常更新通常只需几十秒到几分钟。如需强制全部重抓（例如首次或数据存疑），维护者可用 `--deep-full` 参数运行。

**8. 导出的会员范围是什么？能只导某一级别吗？**
默认导出**所有会员**（含各级别，本次实测 1972 人）。如只想导出某一组别（如仅 VIP会员），运行前设置环境变量即可：
`set LAUNDRY_VIP_GROUP=VIP会员`（对含详情导出、订单抓取同样生效；不设置则不过滤）。

**9. 定时同步和定时关机有什么区别？可以只关机、不同步吗？**
可以，两者**完全独立**，在订单抓取操作台（http://127.0.0.1:8791）分别设置：
- **定时同步**：每天一次或每小时一次，自动执行「会员详情增量 + 订单抓取」并刷新查询页；每天模式可勾选「同步完成后自动关机」（抓完再关）。
- **定时关机**：单独设一个每天的时刻直接关机，不管有没有安排同步。到点前 2 分钟页面顶部弹出红色提示条，点「取消关机」可中止；若到点时正在抓取/导出，会**顺延到数据任务结束后再关**，不会打断同步；电脑当时处于关机状态则本次跳过，次日同一时间再来。

## 技术原理（维护者阅读）

洗衣管家（`xygjwinapp.exe`）是内嵌 Chromium(CefSharp) 的桌面程序，运行时开启了
本机调试端口 `127.0.0.1:9222`。本工具通过该端口连接到软件内置页面：

- 会员列表：调用软件自身的 `gettopuserlist` 接口，分页 200 条/次，取回**所有会员**的全部字段（如需仅某一组别，设 `LAUNDRY_VIP_GROUP`）；
- 会员详情：逐会员调用 `getuinfo` 接口，取回标签、卡券、订单列表、充值信息等。

取数完成后在本地生成文件。全部过程只读，不修改软件内任何数据。

- 已验证版本：**洗衣管家 6.1.23**（2026-09 全量取数实测通过）
- 依赖：Node.js（`D:\node.js`）、Python + openpyxl（`%LOCALAPPDATA%\Python`）
- 目录结构：

```
洗衣管家会员导出\
├─ 导出会员数据.cmd            ← 日常入口（几秒完成）
├─ 导出会员数据(含详情).cmd     ← 完整版入口（几分钟，含订单/卡券等，可断点续传）
├─ 打开会员查询页面.cmd         ← 查询台入口：刷新数据并在浏览器打开
├─ 以调试模式启动洗衣管家.cmd   ← 应急：重新打开软件并开启调试端口
├─ 打开订单抓取操作台.cmd      ← 订单抓取操作台入口（开始/暂停/进度/定时同步/关机设置）
├─ 安装开机自启.cmd            ← 注册开机自启：登录后 30 秒后台启动操作台服务（无窗口）
├─ 移除开机自启.cmd            ← 移除上述开机自启（计划任务 XQY-Orders-Console）
├─ README.md                 ← 本说明
├─ 使用说明.html              ← 网页版说明（可打印）
├─ 导出流程图.png             ← 原理简图
├─ 收衣页面\                      ← 前台收衣开单（本地记录+小票打印）
│   └─ index.html
├─ 查询页面\
│   ├─ index.html            ← 会员数据查询台（离线单页）
│   └─ data.js               ← 页面数据（自动生成/刷新）
├─ 微信AI助手\
│   ├─ 启动.cmd              ← 服务号AI客服：自动回复查订单/余额/会员信息
│   └─ 使用文档.md           ← 服务号接入与部署指南
├─ app\
│   ├─ export.mjs            ← 取数脚本（Node，无第三方依赖）
│   ├─ make_xlsx.py          ← Excel 生成脚本（Python + openpyxl）
│   └─ build_viewer.py       ← 查询页面数据生成脚本
├─ .dev\                     ← 维护调试脚本（可忽略）
└─ 导出结果\                  ← 每次导出的文件与比对缓存（.detail_cache.json）都在这里
```
